# Planet preview data attribution

- Land and coastlines: Natural Earth, public domain.
- Bundled preview relief: coarse visual proxy derived from public-domain ETOPO1 colour relief; it is not a scientific elevation product and must not be used for navigation.
- Production import target: GEBCO Bathymetric Compilation Group 2026 (2026), *The GEBCO_2026 Grid — a continuous terrain model for oceans and land at 15 arc-second intervals*, DOI 10.5285/4f68d5c7-45eb-f999-e063-7086abc036fa.
