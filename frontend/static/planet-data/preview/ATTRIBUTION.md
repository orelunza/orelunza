# Planet preview data attribution

- Land and coastlines: Natural Earth, public domain.
- Country boundaries: Natural Earth low-resolution Admin-0 compatible country polygons, public domain.
- Bundled preview relief: coarse visual proxy derived from public-domain ETOPO1 colour relief; it is not a scientific elevation product and must not be used for navigation.
- Production elevation target: GEBCO Bathymetric Compilation Group 2026, *The GEBCO_2026 Grid*.
- Bundled ecology: deterministic Orelunza development proxy. It is not measured ESA WorldCover or Copernicus LCFM data.

Production ecology packs must be generated from properly licensed source rasters and retain the source attribution in the pack manifest.
